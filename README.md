MeridiaStats is the national statistics site of the Republic of Meridia (capital Meridia City): five pages — overview, population, economy, people & work, and a data explorer — with 14 indicators over 2019–2026, hand-rolled SVG charts, a year selector, a sortable region table, live search and a CSV download. Every figure is internally consistent: regions sum to the national population, sector shares sum to 100%, and the labour force equals employed plus unemployed. Static files, no network requests, no account, nothing placeholder.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or just open `app/index.html` in a browser. No build step, no network requests, no account.
